# Гаранты — мониторинг гарантов и поручителей (soft collection, РК)

Материалы проекта:

- **garanty_monitoring.ipynb** — ноутбук: сбор (Oracle/PostgreSQL/Vertica) → предобработка →
  анализ → feature engineering → классификация гарантов по сегментам → дашборд мониторинга.
- **methodology_skill.md** — методология проекта (правовая рамка ГК РК, маска уровней доступа,
  целевые величины, портрет, антифрод, валидация).
- **uml/** — схемы процесса (Mermaid `uml_scheme.md`, PlantUML `component.puml` / `activity.puml`,
  PDF).

Данные в ноутбуке синтетические. Юрисдикция — Республика Казахстан.
